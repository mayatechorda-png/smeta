# Смета за 5 минут

«Смета за 5 минут» — веб-приложение, в котором можно быстро составить смету или коммерческое предложение и сохранить документ в PDF.

- Предприниматели могут подготовить коммерческое предложение для клиента.
- Офисные сотрудники могут составить смету закупки или перечень расходов для руководителя.

## Файлы приложения

| Файл | Назначение |
| --- | --- |
| `index.html` | Структура страницы с полями, строками сметы, итоговой суммой и кнопками. |
| `styles.css` | Оформление страницы для компьютера, телефона и печати. |
| `script.js` | Обработка строк сметы, расчёт и форматирование сумм, запуск печати для сохранения в PDF. |

## Как открыть

Когда файлы приложения будут готовы, дважды щёлкните по `index.html`. Страница откроется в браузере.

## Как проверить расчёт

1. В первой строке укажите количество 2 и цену за единицу 15 000 ₸.
2. Во второй строке укажите количество 1 и цену за единицу 8 000 ₸.
3. Проверьте итоговую сумму. Должно получиться **38 000 ₸** (2 × 15 000 + 1 × 8 000).
