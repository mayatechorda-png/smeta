# Правила работы над проектом

- Работай только в этой папке. Перед изменениями прочитай текущие файлы проекта.
- Делай только ту функцию, которую просит пользователь. Сохраняй работу уже реализованных функций.
- Используй только обычные HTML, CSS и JavaScript. Не используй npm, фреймворки и внешние ресурсы.
- Храни данные пользователя в браузере. Не отправляй данные в интернет.
- Используй понятные подписи. Поля и кнопки должны быть не меньше 44 пикселей по ширине и высоте. Интерфейс должен работать с клавиатуры и на телефоне.
- Показывай суммы с пробелами между разрядами тысяч и со знаком тенге, например 15 000 ₸. Пустые и неверные числовые значения считай нулём. Никогда не показывай `NaN`.
- Не запускай Git и ничего не публикуй без просьбы пользователя.
- После работы перечисли изменённые файлы и объясни, как проверить результат.
